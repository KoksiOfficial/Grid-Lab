Мета роботи
Перенести обчислювальний двигун Монте-Карло з Docker Compose у кластер Kubernetes (Minikube), налаштувати автоматичний моніторинг життєздатності подів, виконати пакетний розрахунок через `Job` та побудувати фінальний порівняльний бенчмарк продуктивності трьох архітектур.

Завдання

1. Підготовка локального кластера:
   * Розгорнути Minikube (`minikube start --driver=docker --cpus=2 --memory=3072`).
   * Активувати збирач метрик: `minikube addons enable metrics-server`.
   * Завантажити обчислювальний образ у кластер: `minikube image load <image-name>:latest` (без публікації на Docker Hub).

2. Декларативне розгортання сервісу (Deployment + Service):
   * Створити маніфест `deployment.yaml`:
     * Кількість реплік: щонайменше 2.
     * Ресурсні обмеження: обов'язкові `requests` та `limits` по CPU та RAM (захист від вичерпання пам'яті хоста).
     * `imagePullPolicy: IfNotPresent` (запобігання помилці `ImagePullBackOff`).
     * `livenessProbe` та `readinessProbe` на ендпоінт `/api/health`.
   * Створити маніфест `service.yaml`: відкрити доступ через `NodePort` або організувати доступ через `kubectl port-forward`.

3. Пакетні масові обчислення (Batch Job):
   * Створити маніфест `job-batch.yaml`:
     * Параметри паралелізму: `parallelism: 2` (або більше), `completions: 4` (або більше).
     * Політика перезапусків: `restartPolicy: OnFailure`, встановлений ліміт повторів `backoffLimit`.
   * Запустити Job та проконтролювати перехід подів у стан `Completed`.

4. Експорт результатів без монтування Persistent Volumes:
   * Отримати підсумковий звіт розрахунків безпосередньо з логів завершеного Job:
     ```bash
     kubectl logs -l job-name=powergrid-batch > benchmark_k8s.json
     ```

5. Фінальний порівняльний бенчмарк:
   * Звести отримані результати з попередніх етапів у єдину таблицю у звіті:

| Критерій | Bare-Metal (Етап 1, MIMD PC) | Розподілений Ray (Етап 2/3, Docker) | Kubernetes Job (Етап 4) |
| :--- | :--- | :--- | :--- |
| **Рівень ізоляції** | Спільна пам'ять процесу | Контейнери Docker | Поди (cgroups v2 + netns) |
